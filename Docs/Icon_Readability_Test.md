# Icon readability test with children 5 to 9 (US 5.2)

Goal: check that a child understands each HUD icon **without explanation**.
Pass criterion: an icon is validated when **at least 4 children out of 5** (80 %) give the right meaning.
An icon that fails is redrawn in `HudRestyle.cs`, then tested again.

## How to run it (about 5 minutes per child)

1. Use a tablet with the game paused, or print the screenshot of the HUD (Game view, 1920x1080).
2. With a parent's or teacher's agreement, sit with **one child at a time** (5 children minimum, ages 5 to 9, mixed).
3. Point at one icon and ask in Arabic: **"ماذا يفعل هذا الزر؟"** ("What does this button do?"). Do not name it, do not hint.
4. Write the child's exact answer, then mark: ✓ right, ~ close, ✗ wrong / no idea.
5. At the end, ask the child to "drive": watch whether they find Go, Stop and the seatbelt alone.
